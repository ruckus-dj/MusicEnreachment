# React-макет MeloTrove

Самостоятельный графический эталон. Требования — в
[продуктовом контракте](../design/decisions.md#интерфейс).

- `src/ui/` — `MeloTroveUI`, маршруты, экраны и контракт `MeloTroveProvider`.
- `src/demo/` — демо-провайдеры, сценарии и данные.
- `src/app/main.tsx` — единственная точка входа макета.
- `src/test/` — общие тесты и настройка тестовой среды.

Макет развивается независимо и может опережать приложение. По явному
запросу владельца всё дерево `src/ui/` копируют в приложение с сохранением
относительных путей; постоянная синхронизация или обязательная побайтовая
сверка деревьев не требуется. Точка входа подключает production-реализацию
`MeloTroveProvider` вместо демо-реализации.

Из корня репозитория: `task design:run` запускает макет на порту 5175;
`task design:check` проверяет и собирает его.
