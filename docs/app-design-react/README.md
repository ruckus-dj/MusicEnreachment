# React-макет MeloTrove

Самостоятельный графический эталон. Требования — в
[продуктовом контракте](../design/decisions.md#интерфейс).

- `src/ui/` — `MeloTroveUI`, маршруты, экраны и контракт `MeloTroveProvider`.
- `src/demo/` — демо-провайдеры, сценарии и данные.
- `src/app/main.tsx` — единственная точка входа макета.
- `src/test/` — общие тесты и настройка тестовой среды.

Макет может опережать приложение: новый дизайн и UX проверяют здесь, а затем
по запросу владельца переносят всё дерево `src/ui/` в приложение. Правки UI,
сделанные непосредственно во frontend, в той же задаче переносят обратно
в макет, в том числе добавления, переименования и удаления. Переносят сами
правки, не затирая экспериментальный UX, чтобы следующий перенос из макета
их не потерял. Провайдеры, данные и точки входа у приложения и макета свои.

Из корня репозитория: `task design:run` запускает макет на порту 5175;
`task design:check` проверяет и собирает его.
