# Отдельный React-прототип MeloTrove

Перенос исходного интерактивного прототипа, **не завершённая замена**.
Приложение в `frontend/` не изменяется; старый макет в `../app-design/`
сохраняется для сравнения. Исходная зафиксированная версия: `536098d`.

Из корня репозитория:

- `task design:run` — отдельный Vite-сервер на порту 5175.
- `task verify` — общий gate, включая TypeScript, тесты и сборку стенда.
- `/compare` — живое сравнение с исходным прототипом, без screenshot-артефактов.

Стек: React 19, TypeScript, Vite, Tailwind 4, React Aria Components;
TanStack Query включён в зависимости для асинхронных демонстрационных сценариев.
Зависимости и lockfile отдельные. Результат сборки — `build/design-prototype`,
не `build/frontend`; прототип не встраивается в сервер приложения.

`export-fixtures.mjs` экспортирует полные данные старого макета без переписывания
идентификаторов, тегов, снимков, locations и recovery evidence. Gate проверяет
побайтовое совпадение экспорта и SHA-256 источника. Преобразование в упрощённую
модель каталога выполняется только при отображении; исходные данные не теряются.

Состояние переноса и известные отличия — в [PARITY.md](PARITY.md).
Не считать успешный gate доказательством полного визуального или сценарного
паритета. Экран сравнения явно отмечает отсутствующие маршруты.
