# React-макет MeloTrove

Самостоятельный графический эталон. Требования — в
[продуктовом контракте](../design/decisions.md#интерфейс).

- `src/ui/` — переносимые экраны, маршруты, нейтральные тексты и контракты
  провайдеров. Здесь нет демо-данных, демо-действий и подписей макета.
- `src/demo/` — демо-провайдеры, сценарии, данные и подписи макета.
- `src/app/main.tsx` — единственная точка входа макета.
- `src/test/` — общие тесты и настройка тестовой среды.

Макет может опережать приложение: новый дизайн и UX проверяют здесь, а затем
по запросу владельца копируют всё дерево `src/ui/` в `frontend/src/ui/`,
включая добавления, переименования и удаления. Перед копированием в макет
встраивают независимые правки приложения, не затирая более новые изменения.
После копирования `diff -qr` не должен находить различий. Провайдеры, данные
и точки входа у приложения и макета свои.

Из корня репозитория: `task design:run` запускает макет на порту 5175;
`task design:check` проверяет и собирает его.
