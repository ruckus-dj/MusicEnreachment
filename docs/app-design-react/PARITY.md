# Перенос графического прототипа

Основание сравнения: старый прототип `docs/app-design` в коммите `536098d`.
Старый прототип сохраняется. Перенос не разрешает новые продуктовые решения.
Владелец разрешил полную графическую переработку React-стенда с приоритетом
UI/UX и использованием React Aria Components. Визуальная приёмка владельцем
ещё не выполнена; наличие компонентов и зелёных тестов её не заменяет.

## Графическая переработка

Уточнение владельца: медиатека пополняется только через записи провайдеров.
Если нужного релиза нет, запись создаётся у провайдера Local в «Собственном
каталоге», затем явно выбирается для сопоставления входящих. Создание записи
каталога само по себе не добавляет релиз в медиатеку. Прямой обходной сценарий
ручного создания удалён; прежняя ссылка `#create-release` ведёт в `#local`.
Служебное сравнение остаётся по `/compare`, без ссылки в заголовке медиатеки.

Общие оформленные компоненты находятся в `src/ui/index.tsx`: таблицы, поля,
поиск, выборы, флажки, радиогруппы, вкладки с панелями, раскрывающиеся секции,
диалоги, панели действий и навигационные ссылки React Aria. Оформление экранов
разделено между общей системой и стилями каталога, форм и сопоставления.

Живой браузерный проход охватил 13 основных маршрутов на ширинах 375, 768 и
1440 px; отдельное ревью проверяло обе темы и клавиатурные взаимодействия.
Это целевые проверки, а не доказательство исчерпывающей визуальной приёмки.
Скриншоты не создавались. Последний полный gate прошёл до завершающих правок
выбора издания и единообразия действий; итоговое дерево проверяет normal hook.

## Критерий завершения

Для каждого экрана сверить структуру, поля, данные, состояния и действия в двух
живых версиях; проверить клавиатуру, фокус, обе темы, узкий и широкий экран.
Наличие React-компонента или успешная сборка сами по себе не доказывают паритет.
Различия фиксировать явно; не заменять отсутствующие действия выдуманными.

## Инвентарь

Перечни тегов в этом инвентаре описывают частичное покрытие макета, не целевые
требования. Полный реестр пользовательских метаданных Navidrome, отдельное
`artist.sort_name`, уточнение и множественный genre-picker заданы в
[`navidrome-metadata.md`](../design/navidrome-metadata.md). Отсутствие поля в
fixtures/API не разрешает исключить его из дизайна. Сведения артиста/издания
редактируются на месте; сравнение конкретного source/publication относится к
треку и не заменяет эти формы.

| Область старого прототипа | Текущее состояние переноса |
|---|---|
| Shell, навигация, системная/светлая/тёмная тема | Перенесена основа оболочки и те же разделы; неперенесённые маршруты помечены явно, нужна финальная сверка |
| Медиатека: артисты, все альбомы, все треки | Частично; структура и статистика пока отличаются |
| Поиск, наличие, публикация | Фильтры управляются общими props экрана и применяются к данным в памяти; URL-состояние не перенесено |
| Выбор групп и позиций, исключение, дедупликация | Базовый выбор перенесён; требуется полная сверка |
| Артист: издания, полные списки треков, фильтры | Перенесены отдельная страница, списки позиций, статистика, фильтры и подтверждение удаления; поиск отсутствующих изданий и фильтры работают в памяти, без требования URL |
| Отсутствующие альбомы, явный выбор издания | Сравниваются год, страна, формат, уточнение издания и названия треков; выбор не добавляет запись в медиатеку |
| Издание: свойства, теги, публикация, удаление | Частично: свойства, полный список, сравнение метаданных издания, контекстный предпросмотр и запрос удаления; нужна сверка полноты отображаемых тегов |
| Позиция: варианты источников и выбранный исходник | Частично: явный выбор без изменения текущей публикации; остальные действия не перенесены |
| Сравнение тегов исходник/провайдер/локально/публикация | Перенесены отдельный маршрут, три области сравнения, выбор файла и фильтр отличий; требуется финальная сверка |
| Метаданные и снимок публикации | Экран композиции показывает изменённые поля TITLE, ARTIST, ALBUM, ALBUMARTIST, DATE, COUNTRY, LABEL, CATALOGNUMBER, TRACKNUMBER, DISCNUMBER, GENRE, а также coverHash и lyrics; публикация показывает путь и снимок тегов/времени чтения. Свежие предпросмотры аудио и метаданных разделены |
| Массовый и одиночный предпросмотр и подтверждение | Массовый, одиночный и контекстный предпросмотр применяются в памяти; контекстная публикация требует финального подтверждения, повторно проверяет версию инвентаря и сохраняет невыбранные позиции и исходники. Полный lifecycle и прочие сценарии устаревания ещё требуют сверки |
| Явная перепубликация и подтверждение даунгрейда | Перенесены в память React-макета; требуется финальная сверка с остальными lifecycle-сценариями |
| Входящие, кандидаты, назначения, DnD и клавиатура | Частично: группы, автоматика, отдельные черновики изданий, несколько источников, поиск композиций, теги и частичная публикация; требуется подробная браузерная сверка DnD и клавиатуры |
| Ручной сборник, носители, позиции и черновик | Перенесены поля, порядок, авторство, исходники и создание в общей медиатеке; требуется финальная сверка |
| Собственный каталог: артисты/релизы/композиции | Перенесён отдельный Local-каталог с исходными идентификаторами, явным созданием, редактированием и ссылками внешних провайдеров; требуется финальная сверка |
| Источники: добавление, режимы, удаление и запреты | Частично: общая модель инвентаря, режимы, выбор папки, запрет удаления при активной операции и очистка черновиков входящих без автоматического выбора замены; нужна финальная сверка |
| Операции: текущие ошибки, повтор и восстановление | Перенесены текущие ошибки, обычный повтор, восстановление регистрации и очереди запросов удаления; нужна финальная сверка |
| Настройки: пути, инструменты, жанры, смена каталога | Перенесены демонстрационные действия и общий каталог жанров; нужна финальная сверка обеих тем и размеров |
| Первый запуск и выбор серверного каталога | Перенесены четыре шага, проверка пути, необязательные жанры; шаг сохраняется при навигации; нужна финальная сверка |
| Витрина компонентов | Перенесена; требуется финальная сверка |

## Ограничения проверки

- Полный экспорт исходных fixtures заменил сокращённый JSON; проверка дрейфа
  включена в gate. Отображение каталога всё ещё упрощено.
- Общая композиция React Aria проверяется отдельно от графической приёмки;
  проверка контраста, экранных дикторов и всех состояний не исчерпывающая.
- Отдельные TypeScript, тесты и Vite-сборка подключены к `task verify`.
- Зависимости установлены отдельно; `frontend/` не изменяется.
- `/compare` показывает две версии рядом для медиатеки; неперенесённые маршруты
  явно помечены, а не заменены выдуманными экранами.
