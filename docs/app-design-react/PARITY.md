# Перенос графического прототипа

Основание сравнения: старый прототип `docs/app-design` в коммите `536098d`.
Старый прототип сохраняется. Перенос не разрешает новые продуктовые решения.
Текущий React-стенд неполон и не заменяет графический эталон.

## Критерий завершения

Для каждого экрана сверить структуру, поля, данные, состояния и действия в двух
живых версиях; проверить клавиатуру, фокус, обе темы, узкий и широкий экран.
Наличие React-компонента или успешная сборка сами по себе не доказывают паритет.
Различия фиксировать явно; не заменять отсутствующие действия выдуманными.

## Инвентарь

| Область старого прототипа | Текущее состояние переноса |
|---|---|
| Shell, навигация, системная/светлая/тёмная тема | Перенесена основа оболочки и те же разделы; неперенесённые маршруты помечены явно, нужна финальная сверка |
| Медиатека: артисты, все альбомы, все треки | Частично; структура и статистика пока отличаются |
| Поиск, наличие, публикация | Частично; нет URL-состояния и полных пустых состояний |
| Выбор групп и позиций, исключение, дедупликация | Базовый выбор перенесён; требуется полная сверка |
| Артист: издания, полные списки треков, фильтры | Частично; пока упрощённый список |
| Отсутствующие альбомы, явный выбор издания | Частично; требуется сверка области поиска и фильтров |
| Издание: свойства, теги, публикация, удаление | Частично: свойства, полный список, контекстный предпросмотр и запрос удаления; теги издания не перенесены |
| Позиция: варианты источников и выбранный исходник | Частично: явный выбор без изменения текущей публикации; остальные действия не перенесены |
| Сравнение тегов исходник/провайдер/локально/публикация | Частично: на странице позиции доступны три области и фильтр отличий; отдельный маршрут и выбор файла не перенесены |
| Метаданные, снимок публикации, внешнее изменение файла | Не перенесено |
| Массовый и одиночный предпросмотр и подтверждение | Частично: массовый, одиночный и контекст издания с применением в памяти; защита устаревшего инвентаря не перенесена |
| Явная перепубликация и подтверждение даунгрейда | Перенесены в память React-макета; требуется финальная сверка с остальными lifecycle-сценариями |
| Входящие, кандидаты, назначения, DnD и клавиатура | Частично: группы, автоматика, отдельные черновики изданий, несколько источников, поиск композиций, теги и частичная публикация; требуется подробная браузерная сверка DnD и клавиатуры |
| Ручной сборник, носители, позиции и черновик | Не перенесено |
| Собственный каталог: артисты/релизы/композиции | Не перенесено |
| Источники: добавление, режимы, удаление и запреты | Частично: общая модель инвентаря, режимы, выбор папки, запрет удаления при активной операции и очистка черновиков входящих без автоматического выбора замены; нужна финальная сверка |
| Операции: текущие ошибки, повтор и восстановление | Перенесены текущие ошибки, обычный повтор, восстановление регистрации и очереди запросов удаления; нужна финальная сверка |
| Настройки: пути, инструменты, жанры, смена каталога | Перенесены демонстрационные действия и общий каталог жанров; нужна финальная сверка обеих тем и размеров |
| Первый запуск и выбор серверного каталога | Перенесены четыре шага, проверка пути, необязательные жанры; шаг сохраняется при навигации; нужна финальная сверка |
| Витрина компонентов | Не перенесено |

## Известные ограничения заготовки

- Полный экспорт исходных fixtures заменил сокращённый JSON; проверка дрейфа
  включена в gate. Отображение каталога всё ещё упрощено.
- React Aria Checkbox и модальное подтверждение подключены; остальные контролы
  ещё требуют сверки. Цветовые токены обеих тем и оболочка перенесены.
- Отдельные TypeScript, тесты и Vite-сборка подключены к `task verify`.
- Зависимости установлены отдельно; `frontend/` не изменяется.
- `/compare` показывает две версии рядом для медиатеки; неперенесённые маршруты
  явно помечены, а не заменены выдуманными экранами.
