# Планы

- `todo/` — согласованные, достаточно декомпозированные этапы: готовые к
  реализации или уже выполняемые.
- `to-decompose/` — будущие области и сохранённые решения, которые нельзя брать
  в реализацию без повторной проработки и разбиения на короткие понятные этапы.
- `done/` — завершённые планы, прошедшие независимую приёмку.

## В работе

- `todo/03-source-inventory-first-slice.md` — этапы 1–9 реализованы, этап 10
  (документация и полный gate) выполняется. План **в работе**, а не завершён:
  перенос в `done/` возможен только после независимой приёмки, когда проверяющий
  агент повторно запустит `task verify` и построчно сопоставит критерии готовности
  плана с кодом, миграциями, тестами и реально пройденным UI. До этого вердикта
  файл остаётся в `todo/`.
