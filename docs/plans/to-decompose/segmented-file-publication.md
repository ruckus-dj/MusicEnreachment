## Сохранённые ограничения

- Существующие source links и CUE/manual boundaries сохраняются; matching
  semantics не меняются из-за отсутствия публикационного extraction.
- Пока область не реализована, UI сообщает о неподдерживаемой публикации
  сегментов. Игнорировать границы и публиковать целый образ вместо позиции нельзя.
- Автоматического разделения без явной разметки нет.
- Действуют согласованные правила публикационного качества, writer и output
  lifecycle; этот план не разрешает новые перекодировки или скрытый fallback.

## Проработка перед реализацией

1. Проверить текущую модель границ и связь позиций с общим source.
2. Согласовать точность extraction, округление и допустимые погрешности;
   обработку pregap, последнего сегмента, пересечений и устаревшей разметки.
3. Исследовать реальную точность stream-copy по поддерживаемым кодекам.
   Не обещать sample-accurate extraction без технического подтверждения.
4. Если потребуется перекодирование, отдельно согласовать его допустимость,
   качество и представление предупреждений; молчаливого fallback нет.
5. Определить поведение preview, исправления разметки, assets и synced lyrics
   при изменении временной шкалы. Автоматический retiming не утверждён.

## Будущая проверка

Реальные CUE/manual fixtures: несколько позиций из одного файла, граничные,
пустые и невалидные сегменты, source freshness, повторная доставка и recovery,
совместная защита общего source от преждевременного удаления. Проверять готовые
аудиофайлы и теги, не только DB state. Локальный gate — `task verify`.
