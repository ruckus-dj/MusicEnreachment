# Двухэтапное автоматическое сопоставление

Статус: на декомпозицию. Не входит в перенос Local на общий экран
сопоставления и не меняет текущий алгоритм или настройки автопубликации.

## Предложенный поток

1. **Найти издания-кандидаты.** Из группы входящих получить количество готовых
   файлов, название альбома и исполнителя релиза. По метаданным уровня релиза
   отобрать ограниченный список изданий. Этот шаг не назначает файлы позициям
   и не подтверждает связи.
2. **Оценить распределение внутри каждого кандидата.** Для каждого из короткого
   списка взять доступный треклист, рассчитать баллы пар «файл → позиция» и
   найти лучшее допустимое распределение всего набора. Сравнивать между собой
   распределения, а не максимальные баллы отдельных пар. Local и MusicBrainz
   используют один расчёт; различается подготовка входных данных.
3. **Выбрать издание и запустить автоматику.** Если несколько изданий дали
   одинаково лучшее допустимое распределение, выбирать детерминированно,
   например по возрастанию стабильного ID издания. Порядок ответа провайдера
   или загрузки из БД не должен менять результат. Если победившее
   распределение проходит порог и проверки актуальности, запускается
   автосопоставление, а после него — автопубликация при её штатных условиях.
   Если порог не пройден, оставить группу на ручной разбор.

## Перед реализацией

- Определить размер короткого списка и правила отбора при неполных тегах,
  разных размерах изданий и сборниках. Посчитать риск, что правильное издание
  отсеивается до расчёта дорожек.
- Зафиксировать критерий сравнения распределений и порог, а отдельно —
  поведение при нескольких равных распределениях **внутри** одного издания.
  Выбор между изданиями по ID не разрешает неоднозначность на уровне дорожек.
- Замерить время полного пути: загрузка данных, расчёт и распределение;
  сравнить расчёт по запросу с чтением сохранённых оценок. Не считать
  предрасчёт всех пар обязательным. Отдельно определить, какие входные данные,
  ревизии и результаты решения нужны для проверки актуальности, повторной
  доставки и аудита автопубликации.
- Проверить на одних и тех же данных Local и MusicBrainz, перестановку
  кандидатов, границу порога и изменение группы или издания перед применением.
