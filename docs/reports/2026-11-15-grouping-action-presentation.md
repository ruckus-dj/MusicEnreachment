# Подписи неподтверждённых изменений групп

## Границы

Срез плана 13: заменить технические kind/UUID в описании ожидающих действий
понятными RU/EN подписями, сохранив wire IDs и проверки preview/confirmation.
Предпросмотр показывает будущий результат без сохранения. После успешного
подтверждения список действий очищается; история исходных групп не добавляется.

## Статус проверки

Реализация трёх frontend файлов завершена и отформатирована. Независимое
ревью проверяет подписи последовательных действий, сохранение wire payload
и очистку после подтверждения. Runtime-проверки текущего среза ещё не запускались;
зелёная CI `48a844f6` относится только к предыдущей ревизии.

Независимое ревью выявило несовпадение номеров для следующего действия после
изменяющего группы preview: подпись предпочитала номер исходного снимка вместо
номера, который пользователь выбирает сейчас. Исправление ограничено display
mapping; regression использует преобразованный preview и проверяет отсутствие
исходных групп и списка действий после успешного подтверждения.

Повторное ревью production-кода блокеров не выявило. Тест уточняется:
перемещается файл между разными группами, итоговый ответ отражает новые составы;
пустота списка действий проверяется только в его секции, а не во всех списках
файлов страницы. Wire ID и revision assertions сохраняются.
