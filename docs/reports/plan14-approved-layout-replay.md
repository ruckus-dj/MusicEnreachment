# План 14: контроль утверждённого правила

Сравнение до выбора политики, исходная ревизия и происхождение входов —
в [отчёте T01–T03](plan14-matching-experiment.md). Новый офлайн-режим
использует тот же сохранённый корпус, порог пары `0.70`, общий расчёт
Local/MusicBrainz, отдельную оценку записи для сборников и исправления
кодировки только в памяти. Состояние базы и аудиофайлы не изменяются.

```sh
task matching:experiment -- \
  -input cmd/matching-experiment/testdata/punk-o-mania-2.json \
  -stage policy -threshold 0.70
```

| Группа | Результат утверждённого расчёта |
| --- | --- |
| «Punk-O-Мания 2» | Local, полная раскладка **21/21**, сумма `20.17287`. Автоматический декодер восстановил 68 значений; сомнительные смешанные строки не применялись. |
| «Жечь электричество!» | MusicBrainz, полная раскладка **52/52** на 26 позиций в двух папках; сумма `52.0`. |
| `7bdaad49` | Раскладка **2/2** для `19d437c3…`. Правильное издание в этом срезе не подтверждено, поэтому результат не показывает точность выбора. |

Режим `policy` не подтверждает и не публикует назначения. На этом срезе
подготовлены выбор раскладки, настройка порога и раздельное хранение исходного
и исправленного текста. Привязка решения к текущим ревизиям, запись связей,
повторная проверка после восстановления MusicBrainz и перенос публикаций —
следующие задачи T05. Для переноса недостаточно готовой оценки: при отказе
хотя бы одной нужной новой публикации прежняя CURRENT-копия должна остаться.
