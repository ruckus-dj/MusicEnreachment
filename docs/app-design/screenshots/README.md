# Снимки независимой концепции

## Текущая версия: v2

**[Открыть указатель v2](v2/README.md)**: плотные экраны, светлая и тёмная темы, drag-and-drop, каталог и сравнение тегов. В папке `v2/` находятся свежие снимки после правок пользователя. Файлы с `-draft` в этой родительской папке — промежуточные, не итоговые.

Снимок подтверждения 1440 px показывает ручную замену FLAC на MP3 после первой публикации. Снимок 375 px показывает диалог первой публикации. Это разные сценарии, а не pixel-matched пара.

Desktop-оболочка имеет собственную прокрутку main, поэтому для длинных экранов важно смотреть и основной, и `-bottom` снимок. Мобильные снимки сохраняют всю высоту документа. Для интерактивного просмотра откройте [прототип](../index.html).
