# MeloTrove · независимая концепция интерфейса

**Версия 2: плотный каталог и рабочее место сопоставления.** Обновлено по замечаниям пользователя и его референсам. Частичная публикация и сборники без provider-релиза разрешены пользователем; технические контракты реализации пока не утверждены.

Актуальный контракт медиатеки и публикаций уточнён решением владельца от
2026-11-01 в [`docs/design/decisions.md`](../design/decisions.md#решение-владельца-от-2026-11-01-публикации-в-контексте-медиатеки).
Единственный графический эталон — интерактивный прототип в `index.html` и его
JS/CSS. Снимки удалены по решению владельца от 2026-11-01 и не хранятся и не
перегенерируются на каждую правку; браузерная функциональная и визуальная
проверка сохраняется без сохранения screenshot-артефактов.

Историческое основание первоначальной версии: шесть файлов из [`../design/`](../design/) и требования пользователя того прохода; другая версия дизайна не изучалась, субагенты не использовались и технический дизайн не менялся. Последующие согласованные уточнения описаны в `../design/decisions.md`.

## Посмотреть за пять минут

1. Откройте **[index.html](index.html)** в браузере. Ничего устанавливать не нужно; шрифты, CSS и JavaScript локальные, запросов к провайдерам нет.
2. В верхней панели переключите **«Как в системе / Светлая / Тёмная»**. По умолчанию действует системная тема.
3. Во «Входящих» откройте **Northern Lines**. Слева найдите релиз текстом (`Mira Vale Northern`), справа перетащите `03 - Northbound (live?).flac` на позицию 03. Нажмите на уровень совпадения: в evidence видно расхождение длительности **+12 с**.
4. Перейдите в preview и опубликуйте **8 из 10**. Неизвестный фрагмент остаётся во входящих, позиции 09–10 не требуют вымышленных файлов.
5. Откройте **Road Notes**: у позиции Green Room нажмите «Найти recording», выполните поиск и свяжите результат из Small Hours. Сборник сохраняет собственное имя. Можно снять галочку с неизвестной композиции и опубликовать только четыре позиции.
6. Во входящих «Запустить обработку · демо» показывает автоматическую ветку для **Small Hours: 8/8 уверенных позиций**.
7. В медиатеке переключите **Артисты / Все альбомы / Все треки**. Откройте Mira Vale, раскройте альбомы, перейдите в трек и сравните теги. «Изменить локальное название» демонстрирует, что исходник, провайдер и уже опубликованный файл не меняются вместе с локальной правкой.
8. Откройте отдельную вкладку **Собственный каталог**. Переключите Артисты / Релизы / Композиции, найдите запись, откройте и отредактируйте её; для создания укажите только обязательные поля. В карточке можно выбрать существующую запись любого provider как ссылку.

## Проверить согласованные изменения 1–10

- [Медиатека](index.html#library): фильтр «В наличии / Не хватает / Все», независимые счётчики источников, аудио и публикаций; выбор артистов, альбомов и треков для общего предпросмотра. Самостоятельной вкладки «Публикации» нет.
- [Mira Vale](index.html#artist/mira): два самостоятельных издания Northern Lines и отсутствующий Blue Atlas. У Blue Atlas нет трек-листа до явного выбора издания; варианты содержат 3 и 4 позиции и не объединяются.
- [Northern Lines](index.html#release/north): полный список позиций при любом фильтре; совпавшие строки акцентированы, остальные остаются читаемыми и доступными. «Все» не приглушает строки.
- [Still Water](index.html#track/north-t2): локальные метаданные отличаются от публикации, внешнее изменение файла отмечено отдельно. «Обновить метаданные» открывает предпросмотр ровно этой позиции, не меняя массовый выбор.
- [Home Again](index.html#track/rooms-t8): опубликованный FLAC без исходников остаётся в наличии; обновление его метаданных не требует выбора нового аудиоварианта.
- [Источники](index.html#sources): удаление общей и последней location, отказ при активной операции, сохранение публикации без автоматического выбора MP3. Изменение инвентаря делает старый предпросмотр непригодным к подтверждению.
- [Операции](index.html#operations): восстановление регистрации по совпавшим тегам и техническим параметрам. На странице опубликованного трека доступна отдельная явная перепубликация с подтверждением даунгрейда.
- [Настройки](index.html#settings): SHA-256 при наличии у источника, `-version` для каждого executable и необязательная библиотека жанров.

Это in-memory демонстрация: перезагрузка сбрасывает изменения. Она не обращается к музыкальным провайдерам и не записывает аудиофайлы. Неутверждённый пункт 11 о соотношении общих счётчиков release groups и конкретных изданий не определён этим макетом; частичный каталог провайдера не выдаётся за полную дискографию.

При необходимости HTTP-просмотра из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/app-design
```

Откройте `http://127.0.0.1:8765`. Остановить сервер: Ctrl+C.

## Идея в одном абзаце

Это плотный каталог и редактор назначений: маленькие заголовки, компактные строки, полезные столбцы вместо больших статистических карточек. Релиз, recording, исходник и публикация остаются разными сущностями. Для неполных альбомов есть ручная раскладка, а для личных сборников — независимый поиск recordings. Обе темы используют одинаковую структуру. В демонстрационных данных 4 артиста, 5 альбомов и 37 позиций, все строки каталога открываются.

## Границы демонстрации

- Это проектирование будущего приложения, **не реализация frontend/backend** и не готовый API-контракт.
- Названия артистов, релизов, идентификаторы, версии инструментов, пути и ошибки демонстрационные. Они не получены из MusicBrainz и не описывают реальную медиатеку. Счётчики каталога вычисляются из fixtures. Обложки — авторские абстрактные заглушки.
- Работают текстовый поиск releases/recordings, перетаскивание и добавление связей аудиовариантов, явный выбор источника для публикации, partial-preview, независимые колонки тегов, поиск и виды каталога, отдельный Local provider каталог с in-memory созданием/редактированием всех трёх типов и выбором cross-provider references, тема, одноразовый Setup и отдельная settings-демонстрация update/rollback. Domain-состояние живёт в памяти страницы; перезагрузка его сбрасывает. Только предпочтение темы сохраняется локально, если браузер разрешает.
- Ручное создание collection-релиза доступно из «Медиатека» → «Создать вручную»; записи provider Local доступны отдельно через пункт навигации «Собственный каталог». Оба потока сохраняют изменения только в памяти, серверного сохранения нет.
- **Confidence не имитируется:** утверждённая matching policy описана в [`../design/decisions.md`](../design/decisions.md), но статический макет не рассчитывает confidence или его вклады и не показывает числовой результат. Здесь отображаются только демонстрационные сравнения, Δ длительности и явный fixture-verdict; границы evidence описаны в `03-data-and-evidence.md`.
- Прототип намеренно не сканирует диск, не удаляет файлы, не устанавливает инструменты и не обращается к провайдерам. На соответствующих действиях показана явная пометка демонстрации.
- В Settings смена output показана только как UX-подтверждение: picker выбирает кандидата, демонстрационный селектор иллюстрирует блокировку, но reset не меняет текущий `/srv/music`, очереди, БД, файлы или fixture-публикации.
- В Settings и Setup показана демонстрационная загрузка библиотеки жанров, в Local — поиск и множественный выбор только из неё. Это небольшой офлайн-набор fixtures с демонстрационными ID, не полный каталог MusicBrainz; реальной синхронизации, сети и фонового расписания в макете нет. Продуктовый контракт — в `../design/genres.md`.
- Не каждый подэкран спецификации отрисован отдельно: полнота информационного проектирования находится в `02-screens.md`; визуальная выборка покрывает основные типы задач.

## Как сравнивать с другой концепцией

Оценивайте не только цвета. Пройдите одинаковые задачи: найти издание текстом; разложить неполный альбом; опубликовать часть; найти композиции сборника в разных альбомах; объяснить различие исходных/провайдерных/опубликованных тегов; найти нужный трек в общем каталоге. Сравните число переходов и количество полезных строк на одном размере окна. Открытые технические решения перечислены в конце `01-product-and-flows.md`.

## Уточнение текущего макета · 2026-10-29

- У позиции может быть несколько связанных аудиовариантов и ровно один явно
  выбранный источник для публикации. Добавление варианта не заменяет связи и не
  меняет выбор; повтор той же связи не создаёт дубликат. Публикация использует
  только явно выбранный вариант.
- Текущий текст проверки версии инструментов использует аргумент `-version`.
  Датированные результаты QA не переписываются задним числом.
